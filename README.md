# LaTeX Presentations

A collection of LaTeX (Beamer) source code for slide presentations given by Polina Lemenkova at scientific conferences.

## Organisation
Presentations are organised by the host city of each conference. Each directory contains the LaTeX source (and supporting figures/assets) for one talk.

## Usage
Open the directory for the presentation of interest and compile its main `.tex` file with a LaTeX toolchain (`pdflatex` / `xelatex` / `lualatex`) to produce the slide deck as a PDF.
